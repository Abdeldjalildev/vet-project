# 🐾 VetLife Clinic

VetLife is a modern, responsive web application designed for veterinary clinics and pet owners. It provides a seamless platform to book appointments, manage pet health records via an admin dashboard, explore medical services, and read essential veterinary care tips.

---

## ✨ Features

- Interactive Hero & Booking System: Clean appointment booking form with instant validation and dynamic service selection.
- Admin Dashboard: A structured panel for veterinarians and clinic staff to monitor pet names, types, services, and appointment schedules.
- Comprehensive Services Showcase: Detailed cards covering general checkups, vaccinations, grooming, surgery, and analysis.
- Valuable Veterinary Tips: Categorized care guides for pet health and wellness.
- FAQ Section: Accordion-style answers to common clinic inquiries.
- Dark & Light Mode: Fully adaptive UI supporting both themes for comfortable viewing.

---

## 🛠️ Tech Stack

- Frontend: React, Modern JavaScript (ES6+)
- Styling: Tailwind CSS / Custom CSS
- Build Tool: Vite
- Deployment: Vercel
